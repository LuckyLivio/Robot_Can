# 本轮最终评估：保留 v2 为参考版本，v3 暂不替代

**实验完整完成，但独立确认没有证明 v3 整体优于 v2。** v3 的局部几何测试有改善，开发集也通过了预登记门槛；这些收益没有稳定迁移到新的原生起点。因此应保留 v3 为实验版本，不据此替换 v2。

数值总表、方法和置信区间见 [REPORT.md](REPORT.md)。本页补充主实验完成后的物理回放结论和版本建议。没有改变冻结控制器、权重、阈值或确认样本，也没有撰写论文。

## 为什么开发集改善，独立确认却没有

旧开发失败中确实存在腕部第七关节顶限位。固定等价抓取方向能解决部分已知状态，却不能保证在所有机械臂构型中可达。最终新确认的三个退步案例均已做 v2/v3 成对物理回放，观测与日志逐步完全一致：

| 新确认案例 | 观察到的具体问题 |
|---|---|
| Full s17，无噪声，`demo_6000049` | v2 选择 −90° 并成功；v3 固定选择 +90°，第六关节到限位。第二次对齐仍沿用相同目标，位置误差约 6.8 cm，耗尽恢复次数。 |
| Full s23，无噪声，`demo_6000000` | 同样是 −90° 与 +90° 的差异。v3 第六关节到限位，位置误差约 4.8 cm；v2 成功。 |
| BC，噪声 0.05，`demo_6000005` | 物体中心约 x=0.296，位于目的箱外侧壁附近/壁上，而箱格内侧面为 x=0.29。角落规则未检查“确实在格内”，又向 +x 偏置 6 mm，把抓取目标推向箱外。v2 也曾恢复失败，随后由原基础策略完成；v3 最终未成功。 |

证据文件：[confirmation_regression_physics.json](confirmation_regression_physics.json)、[diagnosis_confirmation.json](diagnosis_confirmation.json)。第三例还涉及恢复时间和基础策略接管时的状态差异，不能只凭版本对比把全部损失归因于 6 mm 偏置；需要拆分消融才能建立更窄的因果结论。

这说明根本问题不是简单地“把超时时限再加长”。**等价的末端抓取方向，不代表机械臂在当前构型中同样可达；靠近一面墙，也不代表物体位于合法箱格内部。**

## 对齐、碰撞和世界模型应怎样解读

- 普通 `phase_timeout` 日志中 ALIGN 事件从 28 减到 23，但最终失败记录以 ALIGN 为最后事件来源的回合从 25 增到 28。事件数量受更长时限及最后一次 `attempt_limit` 的记录方式影响，不能据前一个数字说整体对齐问题已经改善。
- 独立角落压力测试只有 1/4 成功。小测试里消除持续卡碰，不能推导为对任意新姿态都有效；最终目标仍应是避免反复顶墙，而不只是延后超时。
- 本次 v3 Full 在无噪声条件为 160/180，BC 为 54/60；噪声条件 Full 为 166/180，BC 为 54/60。Full−BC 的配对 95% bootstrap 区间分别为 −6.11～+3.33、−2.22～+7.22 个百分点，均跨 0，不能声称稳定优于最强 BC。
- v3 比 v2 少 2 个成功执行回合，只涉及 1 个救回与 3 个新增失败。该结果不支持“升级更好”，也不宜夸大为已经证明总体显著更差。
- bootstrap 的 `[0,0]` 或以 0 为边界的区间，在只有少量不一致结果时可能退化。它描述当前样本，不是严格等价证明，也不是未知起点没有风险的保证。
- 早期同状态对齐分支在回放到既定状态后使用两条相同的无新增噪声分支；它是机制诊断，不等同于在原噪声任务里新增一个独立成功结果。

## 下一步的最小方案（仅建议，本轮未实施）

1. **以 v2 为起点，取消全局固定中性 yaw。** 默认保留 v2 的方向选择；只在可观测的位置/姿态误差持续不下降时，回到安全高度，尝试另一等价方向。第二次尝试必须换策略，不能重复同一个受阻目标。保持总 400 步及两次恢复限制。
2. **给角落规则加合法区域判定。** 仅当物体确实处于已知箱格内部、候选姿态满足掌部和两指间隙时才启用偏置；墙上、格外、狭窄间隙不足的状态走单独的有限回退，不能按“离最近墙更远”盲目移动。
3. 先分别做“方向回退”“角落区域判定”“侧倒掌部倾斜”三项小消融，再组合；保留副作用测试。仅靠当前 v3 对照，无法确定每个组件各自贡献。
4. 这批确认数据已经被观察，应列为已知诊断材料。若后续继续开发，必须重新登记冻结条件和另一批未查看的新起点，不能调完后仍用本批成绩自称独立确认。

## 项目完整度与本科毕业设计适用性

**本轮实验流程完整，性能改进目标尚未全面实现。** 已完成原因诊断、小测试、三轮开发对照、预登记门槛、冻结、全新起点公平确认、配对统计、旧文件保护、逐步控制日志核验和真实物理回放。三类既有问题——抓持确认、失抓恢复、复杂接近/角落抓取——已经有分层证据，但最后一类仍然明显不足。

结合已有的世界模型候选决策、最强 BC 基线、三训练种子和消融实验，项目可以作为本科毕业设计的工程与实验基础。应把贡献表述为系统实现、失败诊断、共享恢复机制和有边界的对照验证；**不要把 v3 写成已经全面提升的最终算法，也不要将局部工程收益归因于世界模型预测能力变好。** 学校未给正式任务书/评分细则，不能据此保证毕业合格。

实际使用和演示建议继续保留 v2 为参考版本，v3 作为可复查实验分支。当前没有自动切换旧项目、演示入口或任何权重。
