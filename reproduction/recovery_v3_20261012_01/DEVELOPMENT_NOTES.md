# v3 开发过程与边界

本目录为独立实验扩展。v1、v2、原始控制代码、训练权重及已有结果均保留；没有训练新网络，也没有写论文。

## 冻结前的诊断与尝试

1. 对旧开发集 `BC / noise / demo_73` 做逐步物理回放。v2 选取 yaw=π 时，Panda 第七关节到达上限，第二次对齐仍重复同一姿态。以同一受阻状态和同一个 D=2 队列进行等长 110 步分支：原姿态仍有约 6.89 cm 位置误差、0.305 rad 方向误差；等价 yaw=0 在第 85 步达到对齐条件，末尾误差约 1.41 mm、0.0051 rad。这是已知开发样本上的机制诊断，不能算独立测试成功率。
2. 首次长距离分支显示：仅改变等价 yaw 还不够，旧 70 步对齐时限不足以覆盖较远的初始位置及较大转角。v3 根据可观测的位置/姿态误差设置 70–110 步阶段时限，每回合依然只有 400 步、最多两次恢复。
3. 两个训练初始化的目的箱角落起点，v2 的手指在下降阶段持续碰隔板。v3 用固定箱体几何选择斜向抓取，并用实际夹爪间距控制预开口，抓取中心向箱格内侧平移毫米量级。两例均成功。早期低速版没有在控制采样边界检测到接触；后续较快对齐版本其中一例有 2 次短暂接触，另一例为 0。因此结论是减少持续卡碰，不是证明绝对无碰撞。
4. `dev_a` 为 231/240，较 v2 的 229/240 净增 2，零退步，未达到预登记 232/240 门槛。提高高处对齐的平移命令上限后，小测试多救回一个远端起点，但 `dev_b` 仍为 231/240，继续不冻结。
5. 对 `dev_b` 三例下降超时逐步物理回放，发现两例是夹爪掌部碰箱壁，另一例是侧倒物体紧贴隔板导致手指碰撞。将侧倒抓取的掌部按固定箱体几何向内侧适度倾斜，训练初始化的三个侧墙案例由 v2 的 0/3 提升为 2/3。紧贴隔板的一例保留为未解决问题。
6. `pilot_e`：自然训练 8/8、失抓注入 2/2、抓住后停滞 1/1、既有几何 4/4、Full 噪声小测 2/2、新增远端/角落 3/4、侧倒靠墙 2/3。新版本不以小测试全成功为宣称；它满足既有安全回归项、角落改善和对齐机制检查后，进入 `dev_c`。

## 公平性

- 各方法使用相同 23 维当前状态、固定任务目标及箱体/夹爪的已知几何。控制器不读仿真接触、关节限位、真实奖励、成功标志或未来轨迹。接触和关节数据只出现在诊断脚本。
- BC k=2 与 Full 三个固定训练种子采用同一个恢复控制器。原 BC 权重、世界模型权重、候选评分和候选集合保持不变。
- 真实双步动作队列不清空；平移执行噪声保持 0 或 0.05；动作上限依旧为原环境的 [-1,1]；总步数不增加。
- 多次查看同一开发集会产生选择偏差，开发集成绩仅用于选定版本。三个开发版本均保留，不合并作为独立样本。
- 新确认实验必须在门槛通过且代码哈希冻结后才生成；预先登记的 60 个原生 reset 种子全保留，不根据成败筛选。另有 16 个预先登记的几何压力起点，单独统计。
- 工程改进归因于共享恢复控制器，不能将其直接归因于世界模型预测能力变好。统计以独立起点配对，Full 三个训练种子在每个起点内先平均。
