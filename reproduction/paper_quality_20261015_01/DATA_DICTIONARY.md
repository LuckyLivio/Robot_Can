# 图表CSV的字段与计数口径

每张图旁的CSV保存用于绘图的测量或统计值；它们不是新增实验回合，也不全是原始逐回合表。不同图可能重复使用同一来源，19,012条导出行不能当作独立样本。完整小型输入在inputs中，原逐回合/逐步记录的项目路径与哈希见PLOT_SOURCES.json。

统一字段：`panel`区分条件/种子/测量；`series`区分方法或数据系列；`x,y`是下面定义的数值而非图片像素；`low,high`是有提供时的区间界；`n`是该行明确记录的计数分母，空白并不等于零样本。

| 图 | x | y | low/high及注意事项 |
|---|---|---|---|
| F01 | 无 | 无 | 结构示意，CSV只有表头，不是丢失测量 |
| F02a–c、A01、F03 | 真实优化器更新次数 | 标题对应损失/MSE/平均欧氏mm误差/regret | 每种子12点；组5贡献为该组regret/64 |
| F04/F05/F11/F14/A02 | 成功率均值（%） | 方法类别序号 | low/high沿x方向，95%区间；不是y方向误差 |
| F06/F07 | 四种配对类别编号0–3 | 该类别起点数 | 顺序：双方成功、仅Full、仅BC、双方失败；n=60 |
| F08 raw difference | 成功交集中的记录序号 | Full−BC完成步数差 | n为交集大小；负数为Full更快 |
| F08 ECDF | Full−BC完成步数差 | 累计百分比 | 与raw difference为同数据的两种表达，不叠加样本 |
| F09 | 方法内部的种子序号 | 位置RMSE（mm） | 横杠均值从这些值计算；持续性只一个无参数预测器 |
| F10/F15/F18 | 成功率差（百分点） | 对比类别序号 | low/high沿x方向；不是百分比相对增长 |
| F12a/b种子行 | 种子序号 | 成功率（%） | series指具体配置；绘图仅为区分噪声作固定横向分隔 |
| F12a/b mean行 | 配置类别序号 | 种子均值成功率（%） | 与上行同来源；n=30个共享开发起点 |
| F13 | 预测步1–8 | 平均欧氏位置误差（mm） | 均值与三个种子均保留；阴影是从种子计算的样本SD，不是CI。control/calibrated与Full完全一致，原输入仍保留 |
| F16 | 几何层序号 | 成功起点数 | 每层n=4，合计16；不得与原生合并 |
| F17 | 实际控制步，从1开始 | 合并阶段编号 | 0基础策略，1接近/对齐，2抓取/确认，3搬运，4放置/释放，5预算耗尽；每步色块覆盖上一控制区间 |
| A03 | 方法类别序号 | 成功执行/条件数 | n=37或240；图上百分比由y/n计算。240执行共享30起点 |
| A04 | 原trace的控制步 | state_before观测指间距（mm） | 56mm目标与51.5–60.5容差是已有控制参数，不是新测量 |
| A05 | 控制步 | 阶段编号 | series保存完整原mode字符串。0 DESCEND，1 ABORT_RETRACT，2 BLOCKED，−1为其他阶段，图上留白 |
| A06a | 控制步 | state_after末端或物体高度（m） | 成功后不补点 |
| A06b | 控制步 | 目标XY距离（m）或物体轴倾角（度） | 由panel字段区分，不能混为一个单位 |
| A07 | 方法列编号 | 条件成功数 | n=30；两列v6/v11共享起点 |
| A08a/A09a | 控制步 | state_after末端或物体世界高度（m） | panel为eef_z/can_z |
| A08b | 控制步 | panel=goal_xy时为m，gap时为mm | 目标XY为(0.1975,0.4025)m，gap=abs(qpos7−qpos8)×1000 |
| A09b | 控制步 | panel=goal_xy时为m，eef_can时为mm | 物体到目标距离和末端到物体距离必须分开；补齐旧CSV缺少的goal_xy |

新包`build_figures.py`完整定义公式/统计读取和绘图映射。需要原始成功标记或父轨迹分组时，使用inputs中的episodes/summary以及项目对应原文件；不要从图像像素反算主结果。
