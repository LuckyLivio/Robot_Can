# 机械臂抓取放置世界模型：实验合同 v0.1

日期：2026-10-08。本轮为独立机器人实验，不覆盖此前 Atari/Pendulum 工作。尚无效果结论。

## 问题与范围

应用：Franka Panda 将易拉罐从桌面抓起、搬运并放入指定料箱（robosuite PickPlaceCan）。工业对应分拣/装箱的基本操作，不宣称验证真实工厂部署。

研究问题：在候选动作相同、规划预算相同、数据相同的条件下，让世界模型学习抓取失败后果和同一起点下动作的优劣关系，能否比只学习平均状态预测更准确地选择动作、减少闭环失败？

先完成状态输入诊断，确认切口值得研究；此结果不得称为视觉实验。视觉阶段允许 RGB、机器人关节/夹爪/末端自身状态，不允许读取物体真实位置、真实抓持状态、未来图像或候选动作真实模拟结果。仿真真值可作训练标签及独立评价。

## 数据、来源、版本

- 官方数据：robomimic v1.5 Can PH（200 个成功示教）；必要时加入 MG/paired 混合质量数据。记录 URL、SHA256、轨迹数量及版本。
- 仿真：robosuite 1.5.1 + MuJoCo 3.3.0，必须以数据元信息生成环境；禁止混用旧版控制器动作。
- 在训练起点恢复完整仿真状态，以相同候选生成器采集动作分支；分支属于其父轨迹，所有相关分支进入同一数据划分。
- 按完整父轨迹划分训练/开发/封存测试，不按窗口随机划分。公开示教配对数据不自动等价于同一中间状态的反事实分支。
- 开发集用于算法调整。封存测试只有方案和超参数锁定后才运行；若测试后修改算法，须版本升级并使用新的封存种子。

## 算法候选

共享小型编码器/GRU，动作条件递归预测未来表示及机器人状态。基线与改进共享容量、数据、候选动作、训练更新预算。

候选 v0：预测损失 + 失败/任务进度监督 + 同一起点动作分支的排序损失。排序监督由训练仿真分支的实际后果产生。风险评分必须对未来动作有条件依赖；不能只依据当前是否已经失败。

具体损失、评分定义、时域、候选数量、重规划频率以实际实现和每次运行 config 为准；本文件先冻结公平性原则，不把未运行配置写成实测。

排序/风险监督是已有决策感知模型学习思想的应用与改进，尚未证明独立新颖性。论文须与 VAML、DINO-WM、相关机器人失败预测工作比较，不宣称首次发明风险预测。

## 对比与消融

1. BC 基础策略：不使用世界模型（实用参考）。
2. 动作复制/持续性模型：弱基线，只用于诊断。
3. 普通动作条件世界模型：预测监督，统一候选动作重排序。
4. 普通世界模型 + 相同失败/进度监督：控制额外标签带来的收益。
5. 完整候选：加入分支排序监督。
6. 完整候选去掉失败评分：检查失败模块贡献。
7. 直接动作后果评分网络（不递归预测状态）：检查世界模型是否必要。
8. 同模型单步/多步时域敏感性；候选数量敏感性仅在开发集。
9. 仿真真值候选排序：诊断参考，不能当作可部署方法或严格理论上界。

以上是计划清单，只有真实完成并保存原始记录的行才进入结果表；不得将不同信息权限的方法混写。

## 评价与判定

主指标：固定测试起点的闭环任务成功率。辅助指标：抓取/搬运/放置阶段进度、失败次数、完成步数、每次决策耗时、候选排序错误率、动作选择遗憾、多步预测误差。

正式实验至少 3 个独立训练种子；同一测试初始状态/扰动成对比较各方法，报告每种子结果和配对置信区间。不得把相关窗口当独立样本。数据量、初始化变化和动作执行扰动为预声明敏感性轴；默认环境必须保留，不能只报告困难扰动。

预实验先判断普通模型有何失败，以及真值排序是否存在可改善空间。若没有候选覆盖、排序信号或闭环收益，记录负结果并调整开发方案。所有调整保存独立配置与时间，不覆盖旧结果。

必须优于有竞争力的、经过开发集调参的基线，才能支持该比较的优越性。只有胜过弱基线、只有预测误差下降、只有同一训练起点回放，均不能支持闭环方法有效结论。
