# 验证发现的坐标系修复（性能门槛不变）

完整 pilot_a 后的实际运动学复核发现：导出的 FK 朝向来自 gripper grip_site，原 23 维状态的 robot0_eef_quat 则来自末端 body，两者存在固定的 +90° 局部 Z 轴偏置。旧单元测试只核对了 site 参考值，未核对真实控制器使用的 body 朝向。这是实现验证缺陷，不是可达性方法的负面证据。

将这一修复登记为预设两版上限之外的一次验证修复；所有 smoke_a、smoke_b、pilot_a 代码快照与结果保留。原 study_plan.json 不改写。修复仅将 FK 旋转末端转换到观测坐标系，并增加跨回合的独立物理模型对照。IK 迭代数、关节裕量、候选数量、成功门槛和 400 步预算均不调整。

之后运行 pilot_b 五路对照，只有该完整修复后的版本用于采用判断。不会将两批已知起点合并冒充独立样本，不开启新的参数搜索。240 回合开发集仍要求保留全部 v6 成功、至少一个救回以及机制与时耗检查通过。
