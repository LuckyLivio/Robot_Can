启动方式

解压展示包后，在CAN_LAB_DEMO目录终端执行：

python -B portable.py verify
python -B portable.py serve --port 8767 --open

打开 http://127.0.0.1:8767/ 。服务根目录就是展示首页。已有服务时直接打开，端口占用则改8768。
