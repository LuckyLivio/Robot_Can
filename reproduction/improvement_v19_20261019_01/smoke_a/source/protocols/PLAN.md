# v19 实验协议（首次物理运行前固定）

本协议在首次新物理运行前固定机制、比较关系、条件集合和门槛。五项源码绑定静态/保存输入回执通过后生成 `protocol_lock.json`；运行器在正式锁和检查全部通过前拒绝启动。不得根据本轮闭环结果修改门槛或替换源码。草案保留为设计历史。

## 研究问题与改动范围

在完整、实际 v18 的基础上，分别检验有界过渡控制窗口、候选规划预算分配及终端收敛。三个新开关是 `transition_window`、`candidate_budget`、`terminal_settling`。完整保留实际 v18 的 108 个配置字段；新增后共 111 个。三个新开关全部关闭时，必须在全部 9 个已保存 profile 的输入上精确复现实际 v18 的每步动作、诊断、阶段与事件。下述控制细节在首次物理执行前固定，不改变旧阈值。

| 版本键 | 实际控制器和配置 | 本轮用途 |
| --- | --- | --- |
| v17 | 冻结的实际 v17 类，106 个字段 | 实际重跑，特别保护已成功的 12000036 |
| v18 | 冻结的实际 v18 类，108 个字段 | 直接父版本，实际重跑 |
| budget | 冻结的实际 v15 类，原 C-only 配置，100 个字段 | 成功数约束参考；保护不同，不能据此采用 |
| transition | 完整 v18 + 仅 A: transition_window | 有界过渡窗口单项修复 |
| candidate | 完整 v18 + 仅 B: candidate_budget | 候选预算单项修复 |
| settling | 完整 v18 + 仅 C: terminal_settling | 终端收敛单项修复 |
| ab | 完整 v18 + A+B，C 关闭 | 两项交互对照 |
| v19 | 完整 v18 + A+B+C | 完整候选 |

A、B、C 和 AB 全部保留完整 v18，包括 v18 两个开关和所有更早模块；不能描述为从 v17 或原始策略仅加一个功能。三个旧版本必须使用各自真实类，不用 v19 的开关模拟基线。历史保存结果不替代本轮三组实际基线执行。AB−B 可检查已有 B 时加入 A 的差异，完整−AB 可检查加入 C 的差异；本设计缺 AC/BC，不能声称估计了完整三因子所有交互。

- 扩展诊断：沿用已登记的 94 个 profile，每组 94 回合，八组共 **752 个真实评估回合**。
- 开发集：v17、v18、v19 各 240 回合，总计 **720 个真实评估回合**；不能称为总共 240 回合。
- 若全部前置门槛通过才冻结并准备独立确认：v6、v18、v19 各 480 回合，共 **1440 个真实评估回合**，使用事先未用的 60 个新物理起点。主比较 v19−v6，次比较 v19−v18。此时尚不生成新起点、锁、任务或确认结果。
- `regression_6000005` 与 `clearance_profile_6000005` 使用同一物理起点、不同保护配置；不得视为两个独立样本。所有小测试/扩展条件均是已知诊断条件，不能声称独立泛化证据。
- 复用原数据集、demo ID、训练权重、种子、噪声生成规则、方法、故障注入和原 profile 配置。历史配对覆盖只按真实存在、配置相符的结果记录；不假定 v15/v14 有 94 条扩展结果。

2. `known13_full_s41_noise005_demo_13000022 / demo_13000022`。
3. `clearance_profile_6000005 / demo_6000005`。

实际 v17 已成功的 `known_full_s23_clean_demo_12000036 / demo_12000036` 必须保留，不能以原三目标之外为由忽略该回退。原三项目标是原 v14 的失败目标；第三项已经在某些旧版本成功，不能一律称为相对 v15 的新救回。除结果门槛外，还必须通过全部保存输入逐步审计和事先登记的物理回放集合。小测试不通过则停止扩展、开发、冻结和确认；扩展不通过则停止开发及以后阶段。失败版本、诊断和先前结果全部保留。

开发集要求完整 v19 至少 **236/240** 成功，并相对本轮实际 v17/v18 和存在的历史 v6/v13 配对结果零退步。v15/v14 没有本轮对应开发集，不伪造覆盖；若之后找到配置完全相符的旧记录，只登记实际覆盖并纳入零退步检查。主比较的统计置信区间与上述采用门槛分开报告，不以小样本点估计或不同保护的 budget 成功数宣称显著、普遍改进。

## 不可改变的控制与保护

- 每回合 400 步，真实 D2 FIFO，20 Hz 控制接口；不清空、重置、缩短或隐式覆盖队列，不增加物理步数。
- 父版本所有配置不变，包括最多两次恢复尝试、关节余量、几何间隙、姿态/位置阈值、5 帧确认、阶段超时、稳定持物与原失抓计数。短路径仍须通过当前实时几何、关节和物体相对位姿保护。
- 仅使用当前观察、当前关节位置、固定任务目标与控制器已有历史；禁止接触、奖励、成功标签、未来仿真或真值候选结果进入动作选择。
- 过渡窗口必须特别覆盖最终下降到 `CLOSE` 的交接帧。若 `pose_action` 拒绝本帧，父类随后执行的阶段进入逻辑不能让未经认证的动作或关爪穿过保护。
- 路线候选族、工作预算、参考关系和适用范围如下固定。估计控制步数不能未经验证称为物理下界。

## 运行前与运行后核验

先完成源码静态检查、9 个 profile 全关精确回放、启用组件正负例（含单 tick 时钟、最终 CLOSE 帧、窗口超时/失效、保护拒绝、短暂失抓/5 帧失抓、候选累计预算和终端确认、尝试和阶段切换失效），以及与最终 helper 对应、名称执行前确定的独立静态回执。静态回执使用真实 `source_sha256` 映射，核验所有对应源码及保存输入，不能只读取 `passed`。

最终运行锁必须包含新控制器及全部新 helper、实际 v18/v17/v16/v15 和更早继承依赖、权重、数据集、评估器、八组任务、正式协议、机制回执。运行前后哈希相同；每阶段保留源码快照、原始动作/观察/队列、完整结果、逐步审计和物理回放回执。物理回放、保存输入审计、静态检查均不是新增统计样本。

## 三项固定实现与代价

### A：只限制额外阻尼的作用窗口

完整保留 v18 DESCEND 的动作上限（35 mm / 0.15 rad）、相邻已提交名义命令变化限制（上限的 1/3）、最终 float32 动作的混合几何认证（每步≤16 work）、关节余量≥0.04 rad、全开度检查以及原姿态/路径/间隙/超时与最终 CLOSE 保护。仅额外观测运动阻尼在既有 DESCEND 阶段 age 1–3 使用，之后回到原比例进展律，仍经上述全部认证。窗口使用原 age，等待/重定位耗掉的阶段步数不返还、不重启；新尝试按父类原规则进入阶段。既有配置108字段完全不变。

此方案不保证修复首次下降已在第387步才开始的13000022；仍保留这个预定目标，不会因作用域有限而事后移除。静态等价和证书不构成闭环收益证明。

### B：有条件的可选候选及48 work上限

四个有限候选族保留。先检查旧 current_exact，再考虑 current_rotation_inset，其他旧候选相对顺序不变。只有本次搜索的 current_exact 完整搬运路径混合几何、连续IK及原关节余量全部通过，而失败限定于放置阶段局部IK/关节余量时，才准入 inset；否则记录为 unknown/admission_unconfirmed，而非不可达。准入检查耗1 work，计入 inset 总共48 work硬上限。到48仍未完成即 unknown，并继续旧候选；不缓存未完成IK为成功。

保持每调用16 work、单IK目标48迭代、总384 work/24调用和原到达/几何/关节阈值。缓存仅本次搜索，key保留原完整几何/关节/姿态输入；不重置控制时钟。沿用当前观测刚体预测任务区域与名义命令时程检查，它们不是实际物理可达或真实完成步数保证。

已知代价：demo87旧状态允许inset保留；12000036旧状态跳过昂贵inset，离线搜索由198work/13调用降为126work/9调用。但12000011第二次因旧搬运证书不完整而不准入，可能失去短路线机会；已准入后仍可能花最多48work再失败。不得声称普遍省时或绝无回退。新闭环结果以完整72回合为准，不用离线候选替代实际控制。

### C：持物近目标的逐轴积分防越过

只适用既有持物 CARRY/PLACE 的 v17反馈接口。在原60mm近区内，若某轴当前观测速度朝目标运动，且 e−D2·v 在名义延迟内跨零，清除该轴与误差同方向的既有积分偏置，并暂停该轴当步新增积分。其他轴按原算法处理。保持P增益、速度阻尼、动作上限、slew、9mm积分范数上限、1mm混合几何检查及≤16work不变。仍须原9mm/0.08rad与连续5帧等全部到达条件。

此跨零量仅用于控制启发式，绝不作为未来仿真、几何或到达证书。状态只在实际提交认证动作时commit；目标、姿态、阶段、尝试、被其他动作打断或父类暂停时沿用原reset。无触发的动作与原完整receipt保持一致。
