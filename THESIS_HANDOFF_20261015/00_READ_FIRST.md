## 实验不是完美，但可以按限定范围写作

- 原世界模型确认，60 个新起点：Full 无噪声 90.00%、噪声 86.11%，BC k=2 为 85.00% / 81.67%。Full 对 BC 的两条件等权联合差值为 +4.72 个百分点，原配对区间 [0.56,10.28]；Full 对 Plain 的区间跨零。
- 共享恢复 v5：464/480 次执行成功，仍只有 60 个新起点；相对 v4 的 +7 次成功来自 2 个起点，差值区间接触零。v5 下 BC 的均值高于 Full，不能把恢复收益写成世界模型能力提升。
- 36 个已有 checkpoint 的固定集复算显示训练误差下降、开发全状态误差停滞或变差；物体位置误差则改善。评分 regret 会受单个候选组显著影响。“仅预测”配置在已有开发回合中始终回退 k=2。
- 剩余角落碰撞、侧倒窄格、失抓和物体掉出台面的失败均保留。没有纯视觉、真机、多任务或普遍安全保证。

本包适合支持“系统实现、受控实验、失败与边界分析”的本科论文，不支持“世界模型稳定显著击败 BC”或“全面解决抓取恢复”。学校没有提供正式任务书/模板/评分标准；题目、篇幅、格式和最终是否通过仍需导师确认。已有 8 条文献也不能替代完整相关工作阅读。

## 换设备如何使用

复制本文件夹或解压 ZIP 到任意路径。写作、看表、打开图不需要 `.venv`、CUDA、MuJoCo 或重新训练。CSV 为 UTF-8 BOM，可用 Excel 或文本工具打开；论文排版优先选矢量 PDF/SVG，图号按最终章节统一。

新设备有 Python 3.10+ 时，在本包目录运行精简校验（只读文件、核对哈希和索引）：

```powershell
python .\09_tools\verify_package.py --mode writing
```

完整版可核对全部压缩日志并解压到内存流验证原始 SHA（不生成新实验）：

```powershell
python .\09_tools\verify_package.py --mode full
```

只在需要读取某批原始逐步日志时，将该批解压到快照目录；默认拒绝覆盖不同内容：

```powershell
python .\09_tools\restore_traces.py --prefix reproduction/recovery_v5_20261012_01/confirmation/
```

仅为了写论文和看图，不需要执行快照里的训练、评估、重跑或 `verify_stage.py`。一些旧校验会执行物理回放，旧脚本也可能包含本机绝对路径和创建新输出的条件；它们作为历史源码保存，不是本包跨设备写作的必经步骤。

如需查看原机器人前端，在本包目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory .\04_snapshot
```

然后打开 http://127.0.0.1:8766/ 。图包 `03_figures/index.html` 可以直接离线打开，无需此服务。
