# 抓持确认与恢复控制：实施和240回合开发集评估

2026-10-12。实验已实际运行完成；本文是工程评估记录，不是论文。

本次恢复层确实提高了任务完成率：240次新运行中有220次成功，相比逐回合对应的原结果，多救回26次失败，没有将原本成功的回合变为失败。尚有20次失败，不能宣称抓住后不搬运、失抓后无法恢复的问题已经全面解决。

## 实施范围与保存情况

所有新增实现、试运行、日志和图表均位于 `reproduction/recovery_20261012_01/`。旧项目1887个受保护文件的SHA-256全部保持一致，覆盖旧代码、权重、实验结果和演示材料；虚拟环境、IDE配置和缓存不在此清单内。没有训练或替换权重，没有修改旧文档，没有撰写论文。

核心新增实现为 `recovery_controller.py` 和 `evaluate_recovery.py`。其余脚本负责小测试、冻结协议、批量执行、分析和验证。

正常情况下仍执行原BC k=2或原Full决策。恢复控制器依据当前23维特权状态的历史、夹爪开度、夹爪与物体的相对运动以及抬升跟随情况确认抓持；检测停滞或失抓后，执行回撤、对齐、下降、闭爪、试抬、抬升、搬运、放置和撤离。重试最多2次，超限后交回原策略。抓取朝向仅在两个竖直抓取方向中按源料箱墙面间距选择。

它是共享的规则控制器，使用固定目标位置和任务几何，**不是世界模型重新学会了恢复**，也不是只靠相机的策略。BC与Full接入完全相同的控制器。控制器不读取奖励、接触真值、成功标志或模拟器未来；成功标志仅用于原有评测终止。所有动作，包括恢复和小测试中的松爪故障，都经过原D=2队列。20 Hz、400步总预算、原噪声和原成功判据均未改变。

## 小测试与冻结

只使用训练集最前面的8个起点进行工程修正。三个试运行版本及各自源码快照均保留。v1未通过；v2虽然任务成功率改善，但轨迹暴露出阶段超时与误触发；v3修正了这些问题后冻结。没有根据本次开发集结果继续修改控制器。

| 检查 | 实际结果 |
|---|---|
| 夹爪方向 | -1张开，+1闭合；开度约0.078 m与0.002 m |
| 世界坐标与旋转 | 正/负Z实际移动方向正确；目标旋转误差从1.526降至0.005 rad |
| 关闭恢复与原程序逐步对照 | BC干净、BC含噪声、Full含噪声，共6回合、1532步，状态、动作、队列完全一致；Full评分也一致 |
| 训练起点自然行为 | 原6/8成功，新8/8成功；原6个成功回合均无干预 |
| 物理松爪故障 | 2/2最终成功；故障通过动作队列施加，没有重置或移动物体 |
| 抓住后原策略停止移动 | 1/1最终成功，触发held_stall并完成搬运 |
| Full含噪声额外小测试 | 2/2成功 |

稳定抓持是观测规则确认，不能等同于独立的接触真值认证。一次松爪测试由停滞分支接管，另一次由失抓分支接管，二者均最终成功。小样本故障测试证明这条恢复路径能工作，不代表所有失抓都能恢复。

正式协议在UTC 2026-10-12 04:21:23冻结。正式实验为30个相同开发集起点 × 无噪声/0.05动作噪声 × 固定BC及Full的17/23/41三个训练种子，共240次新运行。原方法使用对应已冻结结果作配对参照。开发集是已有开发集，不称为全新独立确认集；此前60个确认起点没有用于此次调参或补测。

## 任务成功结果

| 方法 | 无噪声：原 → 加恢复 | 含噪声：原 → 加恢复 |
|---|---|---|
| BC k=2 | 25/30 → **28/30**（83.3% → 93.3%） | 24/30 → **27/30**（80.0% → 90.0%） |
| Full，种子17 | 25/30 → **26/30** | 25/30 → **29/30** |
| Full，种子23 | 24/30 → **26/30** | 25/30 → **29/30** |
| Full，种子41 | 22/30 → **27/30** | 24/30 → **28/30** |
| Full，三个种子均值 | 71/90 → **79/90**（78.9% → 87.8%） | 74/90 → **86/90**（82.2% → 95.6%） |

Full的90次运行是30个起点重复三个训练种子，不是90个独立起点。BC也没有被重复算成三个独立训练种子。

加入相同恢复层后，无噪声时BC更高，含噪声时Full更高；两种条件合并后，BC为55/60，Full为165/180，**都是91.7%**。因此不能挑选含噪声条件，宣称Full全面优于BC。

使用锁定随机种子20261012、20000次配对起点bootstrap，Full三个训练种子先取起点内均值。区间条件于这三个固定种子，未覆盖任意训练种子的不确定性，也不是独立确认结论。

| 比较 | 无噪声差值，95%区间 | 含噪声差值，95%区间 |
|---|---|---|
| BC加恢复 − 原BC | +10.0个百分点，[0.0, 20.0] | +10.0个百分点，[0.0, 20.0] |
| Full加恢复 − 原Full | +8.9个百分点，[2.2, 17.8] | +13.3个百分点，[3.3, 25.6] |

收益方向支持继续验证这套工程恢复机制；当前证据不足以宣称世界模型在公平加恢复后稳定、显著优于强BC基线。

## 恢复解决了多少，代价是什么

| 方法与条件 | 救回原失败 | 原成功变失败 | 剩余共同失败 |
|---|---:|---:|---:|
| BC无噪声 | 3 | 0 | 2 |
| Full17无噪声 | 1 | 0 | 4 |
| Full23无噪声 | 2 | 0 | 4 |
| Full41无噪声 | 5 | 0 | 3 |
| BC含噪声 | 3 | 0 | 3 |
| Full17含噪声 | 4 | 0 | 1 |
| Full23含噪声 | 4 | 0 | 1 |
| Full41含噪声 | 4 | 0 | 2 |
| 合计（方法/种子/条件的运行次数） | **26** | **0** | **20** |

52/240回合触发了干预。38回合完成观测式重新抓起确认，其中37回合最终完成任务；不能把这37次全部解释为救回原失败，因为其中包含原方法本来能成功的情况。真正的配对净救回为26次。

12个原本成功的回合受到了干预，虽然最后仍成功，但平均多用了83.7步。这说明“没有成功率回退”不等于没有打扰正常动作，触发精度仍有改进空间。

正式开发集的首轮干预原因为50次近物体停滞、2次观测失抓，没有held_stall首轮触发。两次明确观测失抓都未成功：BC干净条件demo_124最终落到工作区域外；Full23干净条件demo_128的重新抓取未通过抬升确认。因此，应将本轮主要收益表述为**停滞后的重新抓取及搬运补救**。抓住后不动的专门机制在训练故障测试通过；自然失抓的通用恢复能力仍不足。

## 剩余20次失败

以下是对全部失败运行的互斥事后归类，不用于更改本轮参数。

| 现象 | 次数 | 证据与限制 |
|---|---:|---|
| 始终未触发恢复 | 6 | attempts=0、最终NORMAL；集中在Full的demo_87、demo_43。40步停滞窗口及近物体条件未同时成立，规则会漏掉绕行或反复接近 |
| 进入恢复但抓取阶段耗尽重试 | 10 | 最终EXHAUSTED、物体仍在桌面高度；多次DESCEND超时，包含物体侧倒和箱格附近情况。侧倒样本物体轴倾角约80–90度，固定竖直抓取不足以覆盖 |
| 物体最终落到工作区域外 | 2 | 最终物体z约0.025 m；当前控制层没有地面拾取能力。其中一次先耗尽抓取重试后再掉落 |
| 恢复开始过晚或过程未在预算内完成 | 2 | BC含噪声demo_43第353步才接管，最终仍RETRACT；Full41含噪声demo_43第393步完成抬升确认，但400步已到，仍LIFT |

下降超时与箱格、物体姿态有关系的解释来自轨迹和几何检查；本轮没有对每个失败做接触归因实验，不能将全部10次都断言为某一处墙面碰撞。

## 整体评估与下一步

本轮授权工作已完成：隔离实现、小测试、冻结、240回合对照、旧文件保护和结果核验均完成。项目现在有可运行的故障检测和恢复链路，适合作为“机器人延迟决策与恢复控制的工程复现和对照研究”的本科毕设素材。学校没有提供正式评分标准，因此这里是依据项目证据的工程判断，不是毕业资格保证。

如果目标是证明世界模型全面战胜强BC，当前结果仍不支持；如果目标是展示一个有清楚边界、能复现、能解释成功和失败的系统，材料已经更充分。不能将共享脚本控制器的收益算作世界模型自身的学习创新，也不能隐去强BC、原成功受干预、残余失败或开发集属性。

建议先保留当前版本作为有收益的冻结版本。若继续改进，另建下一版本，先用训练起点验证两个小改动：

1. 增加任务阶段的长期无进展检测，并给恢复留出足够剩余步数；同时检查原本成功轨迹的误触发，避免简单放宽阈值导致更多干扰。
2. 根据物体轴方向和当前所在箱格选择抓取姿态、下降高度与避障方向，补足侧倒物体和箱格附近的重新抓取。工作区外掉落先保持明确的失败边界，不扩大为地面拾取任务。

这些是下一轮假设，不是本轮已实现或已证实的改进。决定采用当前版或下一版后，再锁定**全新的独立确认起点**做BC加恢复与Full加恢复的公平比较，同时包含预定义失抓、停滞及正常完成测试。旧60个确认起点不能重新包装成首次未见测试；本次240回合也不能在继续调参后继续充当独立测试。此次先不写论文。
