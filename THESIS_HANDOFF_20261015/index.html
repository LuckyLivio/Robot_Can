校验与展示

普通 Python 3.10+ 即可核对本包，不需要原实验环境。

python ./09_tools/verify_package.py --mode writing

完整版可加 --mode full 核对全部压缩轨迹。图包页面可直接离线打开；原机器人前端需在本包目录执行：

python -m http.server 8766 --bind 127.0.0.1 --directory ./04_snapshot

随后访问 http://127.0.0.1:8766/。旧训练/评估入口不属于本次写作使用步骤。
